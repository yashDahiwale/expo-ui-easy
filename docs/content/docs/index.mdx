**expo-ui-easy** is a typed layer over [Expo UI](https://docs.expo.dev/versions/latest/sdk/ui/jetpack-compose/)'s
Jetpack Compose components. It does three things and tries to do nothing else:

1. **Keeps Expo's names.** `Button`, `FilledTonalButton`, `ListItem`, `AlertDialog.Title`, `colors`, `modifiers`: exactly as Expo UI
   documents them. There is no parallel vocabulary to learn.
2. **Uses React Native names only where both worlds share a prop.** `onPress`, `disabled`, `onValueChange`, `style`,
   `testID`, `numberOfLines`, `onChangeText`. See [Naming](/docs/concepts/naming).
3. **Manages the Compose `Host` for you.** Expo UI components must live inside a `Host`. expo-ui-easy creates one when you use a
   component on its own, and gets out of the way when you put a [`Host`](/docs/concepts/host) around a whole screen.

```tsx
import { Host, Switch, Button } from 'expo-ui-easy';

<Host matchContents>
  <Switch value={on} onValueChange={setOn} />
  <Button onPress={save}>Save</Button>
</Host>
```

## What it is not

It is not a design system and does not restyle Expo UI. Android only for now (Jetpack Compose); the repository leaves a
placeholder for SwiftUI. There is no web support.
