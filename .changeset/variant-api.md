Variant families are now one component with a typed prop: `Button variant`, `IconButton variant`, `IconToggleButton variant`, `TextField variant`, `Card variant`, `LoadingIndicator variant` and `FloatingActionButton size`. `Text` gains a `variant` prop for Material 3 type roles.

**Breaking:** removed `FilledTonalButton`, `OutlinedButton`, `ElevatedButton`, `TextButton`, `OutlinedTextField`, `FilledIconButton`, `FilledTonalIconButton`, `OutlinedIconButton`, `FilledIconToggleButton`, `OutlinedIconToggleButton`, `ElevatedCard`, `OutlinedCard`, `ContainedLoadingIndicator`, and the small / large / extended floating action buttons. See the Naming docs for the mapping.
